# Репозиторий для сдачи домашних заданий РИЦП 1 курс 2026-2027 C#

## Что необходимо сделать после форка репозитория

1. Добавить в репозиторий вашего ассистента в качестве коллаборатора. никнеймы ассистов в гитхабе: 
   - БРИЦП 261: `mporo-prog`
   - БРИЦП 262: `mc-gerkud`
   - БРИЦП 263: `FillRomanko`

2. Добавить в корень репозитория файл `profile.md`, в котором нужно указать: 
   1. Ваши ФИО
   2. Вашу группу
   3. Ваш тг в формате `@nickname`

3. Закоммитить и запушить этот файл

## Процесс выполнения домашних заданий

- Перед выполнением каждой новой домашки вы создаете **новую** ветку от последнего коммита ветки `master` и работаете внутри новой ветки. 
- Ветка, в которой выполняется домашка должна называться `ФамилияИО/ДЗ<номер дз>`, например: `КудрявцевГА/ДЗ1`
- Все файлы, связанный с домашкой вы коммитите в эту ветку (в гит можно подгружать файлы с любым расширением, так что вы все еще можете выполнять задания в удобном для вас формате)
- Как только вы завершите выполнения домашнего задания, запушьте изменения на удаленный сервер и создайте `PullRequest` в ветку `master` (напрямую коммитить в мастер-ветку запрещено), поставьте ревьюером своего ассистента. Проверяться будут только файлы, актуальные на момент последнего коммита. 
- После проверки домашнего задания ассистент оставляет в комментариях к ДЗ побальный итог для каждой задачи и указывает, за что был снижен балл в каждой задаче.
